# Recursão

# Definição

- Repetição
- Repetição de forma que utilizando a própria função
- chamamos a função ou o procedimento
- Chamada recursiva
- Função recursiva = com cauda
- Procedimento recursiva = sem cauda
- Parada do algoritimo recursivo
- Controle do fluxo recursivo
- 3 Regras:
  - Saber quando parar
  - Decidr como fazer a próxima ação
  - Quebrar uma jornada recursiv em um passo mais uma jornada recursiva menor
- Recursão com cauda -> Deixa um rastro durante a execução, é armazenado na pilha de memórias
- Recusão sem cauda -> procedimento recursivo; não retorna valor;
- Aplicações:
  - Fatorial recursivo
  - Fibonacci
  - Arbore de dados
